01 / THE CASE

Start with the tension, not the polished screen.

Users crossed several tools, dense tables and disconnected states to complete one task. Exceptions were easy to miss, handoffs were slow, and the interface reflected system structure rather than user intent.

PROBLEM

Too many surfaces

One operational task required jumping between queues, approvals, exception lists and detail pages. The mental model changed at every step.

design riskfragmented attention
REFRAME

Task states, not modules

The redesign reorganized navigation around work states and decisions, then used one shared detail workspace for context, history and action.

design movestate-led IA
02 / DECISION STACK

Show why the interface became simpler.

Focus Lens treats design decisions as the main artifact. Screens support the explanation rather than replacing it.

AKeep the primary queue scannableless noise

Decision 02 · Contextual action

AMove actions beside the evidence they depend onclarity

03 / RESOLUTION

End the case where confidence increased.

The outcome is not “new UI.” The outcome is faster task completion, fewer navigation errors and a reusable interaction model for later modules.
